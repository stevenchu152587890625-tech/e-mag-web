💡 核心物理與數學觀念剖析
  • 正交曲線座標幾何關係：柱座標 $(r, \theta, z)$ 與卡氏座標 $(x, y, z)$ 之轉化關係為 $x = r\cos\theta, y = r\sin\theta, z = z$。位置向量為 $\mathbf{r}(r, \theta, z) = x\mathbf{i} + y\mathbf{j} + z\mathbf{k} = r\cos\theta\,\mathbf{i} + r\sin\theta\,\mathbf{j} + z\mathbf{k}$。
  • 度規尺度因子（Scale Factors）：定義為切線向量之長度 $h_i = \left|\frac{\partial \mathbf{r}}{\partial q_i}\right|$。單位基底向量定義為 $\mathbf{e}_i = \frac{1}{h_i}\frac{\partial \mathbf{r}}{\partial q_i}$。
  • 直交性驗證：$\mathbf{e}_r \cdot \mathbf{e}_\theta = 0, \mathbf{e}_r \cdot \mathbf{e}_z = 0, \mathbf{e}_\theta \cdot \mathbf{e}_z = 0$ 且 $\mathbf{e}_r \times \mathbf{e}_\theta = \mathbf{e}_z$ 構成右手正規正交基底。
📐 完整嚴謹逐步推導詳解
1位置向量與偏微分推導切線向量

在柱座標系統中，空間中任意點的位置向量 $\mathbf{r}$ 表為：

$$\mathbf{r} = (x, y, z) = (r\cos\theta, r\sin\theta, z) = r\cos\theta\,\mathbf{i} + r\sin\theta\,\mathbf{j} + z\mathbf{k}$$

對各座標變數 $r, \theta, z$ 求偏導數：

$$\frac{\partial \mathbf{r}}{\partial r} = \cos\theta\,\mathbf{i} + \sin\theta\,\mathbf{j} + 0\mathbf{k} = (\cos\theta, \sin\theta, 0)$$ $$\frac{\partial \mathbf{r}}{\partial \theta} = -r\sin\theta\,\mathbf{i} + r\cos\theta\,\mathbf{j} + 0\mathbf{k} = (-r\sin\theta, r\cos\theta, 0)$$ $$\frac{\partial \mathbf{r}}{\partial z} = 0\mathbf{i} + 0\mathbf{j} + 1\mathbf{k} = (0, 0, 1)$$
2計算尺度因子 (Scale Factors $h_i$)

取各偏導數向量之歐幾里得範數（長度）：

$$h_1 = h_r = \left|\frac{\partial \mathbf{r}}{\partial r}\right| = \sqrt{\cos^2\theta + \sin^2\theta + 0} = 1$$ $$h_2 = h_\theta = \left|\frac{\partial \mathbf{r}}{\partial \theta}\right| = \sqrt{(-r\sin\theta)^2 + (r\cos\theta)^2 + 0} = \sqrt{r^2(\sin^2\theta + \cos^2\theta)} = r$$ $$h_3 = h_z = \left|\frac{\partial \mathbf{r}}{\partial z}\right| = \sqrt{0^2 + 0^2 + 1^2} = 1$$
3正規化獲得單位向量 (Unit Vectors)

利用公式 $\mathbf{e}_i = \frac{1}{h_i}\frac{\partial \mathbf{r}}{\partial q_i}$：

$$\begin{aligned} \mathbf{e}_r &= \frac{1}{h_r}\frac{\partial \mathbf{r}}{\partial r} = \cos\theta\,\mathbf{i} + \sin\theta\,\mathbf{j} \\ \mathbf{e}_\theta &= \frac{1}{h_\theta}\frac{\partial \mathbf{r}}{\partial \theta} = -\sin\theta\,\mathbf{i} + \cos\theta\,\mathbf{j} \\ \mathbf{e}_z &= \frac{1}{h_z}\frac{\partial \mathbf{r}}{\partial z} = \mathbf{k} \end{aligned}$$

以矩陣形式表示轉化關係為：

$$\begin{bmatrix} \mathbf{e}_r \\ \mathbf{e}_\theta \\ \mathbf{e}_z \end{bmatrix} = \begin{bmatrix} \cos\theta & \sin\theta & 0 \\ -\sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} \mathbf{i} \\ \mathbf{j} \\ \mathbf{k} \end{bmatrix}$$
4微弧長、線元、面積微元與體積微元

全微分弧長向量 $d\mathbf{r}$ 為：

$$d\mathbf{r} = h_r dr\,\mathbf{e}_r + h_\theta d\theta\,\mathbf{e}_\theta + h_z dz\,\mathbf{e}_z = dr\,\mathbf{e}_r + r d\theta\,\mathbf{e}_\theta + dz\,\mathbf{e}_z$$

微分線元素平方度規（Line element squared）：

$$ds^2 = |d\mathbf{r}|^2 = dr^2 + r^2 d\theta^2 + dz^2$$

三方向之微分面積元（Area elements）：

$$dS_r = (h_\theta d\theta)(h_z dz) = r\,d\theta\,dz$$ $$dS_\theta = (h_r dr)(h_z dz) = dr\,dz$$ $$dS_z = (h_r dr)(h_\theta d\theta) = r\,dr\,d\theta$$

微分體積元（Volume element）：

$$dV = h_r h_\theta h_z\,dr\,d\theta\,dz = r\,dr\,d\theta\,dz$$

💡 核心物理與數學觀念剖析
  • 座標定義注意：講義採林琦焜教授文獻符號：$\rho$ 為半徑（即物理上之 $r$），$\phi$ 為與 $z$ 軸夾角（即物理上之天頂角 $\theta$），$\theta$ 為 $xy$ 平面上之方位角（即物理上之 $\phi$）。

1空間位置向量與各座標偏微商

將位置向量寫為三維卡氏分量：

$$\mathbf{r}(\rho, \phi, \theta) = (\rho\sin\phi\cos\theta)\mathbf{i} + (\rho\sin\phi\sin\theta)\mathbf{j} + (\rho\cos\phi)\mathbf{k}$$

分別對 $\rho, \phi, \theta$ 求一階偏導微商：

$$\frac{\partial \mathbf{r}}{\partial \rho} = \sin\phi\cos\theta\,\mathbf{i} + \sin\phi\sin\theta\,\mathbf{j} + \cos\phi\,\mathbf{k}$$ $$\frac{\partial \mathbf{r}}{\partial \phi} = \rho\cos\phi\cos\theta\,\mathbf{i} + \rho\cos\phi\sin\theta\,\mathbf{j} - \rho\sin\phi\,\mathbf{k}$$ $$\frac{\partial \mathbf{r}}{\partial \theta} = -\rho\sin\phi\sin\theta\,\mathbf{i} + \rho\sin\phi\cos\theta\,\mathbf{j} + 0\mathbf{k}$$
2求尺度因子 (Scale Factors)

計算各微商向量之範數長度：

$$h_\rho = \left|\frac{\partial \mathbf{r}}{\partial \rho}\right| = \sqrt{\sin^2\phi(\cos^2\theta + \sin^2\theta) + \cos^2\phi} = \sqrt{\sin^2\phi + \cos^2\phi} = 1$$ $$h_\phi = \left|\frac{\partial \mathbf{r}}{\partial \phi}\right| = \sqrt{\rho^2\cos^2\phi(\cos^2\theta + \sin^2\theta) + \rho^2\sin^2\phi} = \sqrt{\rho^2(\cos^2\phi + \sin^2\phi)} = \rho$$ $$h_\theta = \left|\frac{\partial \mathbf{r}}{\partial \theta}\right| = \sqrt{\rho^2\sin^2\phi(\sin^2\theta + \cos^2\theta)} = \rho\sin\phi$$
3單位向量基底矩陣表示

將微商向量除以對應之尺度因子即可得正規正交單位向量：

$$\begin{aligned} \mathbf{e}_\rho &= \sin\phi\cos\theta\,\mathbf{i} + \sin\phi\sin\theta\,\mathbf{j} + \cos\phi\,\mathbf{k} \\ \mathbf{e}_\phi &= \cos\phi\cos\theta\,\mathbf{i} + \cos\phi\sin\theta\,\mathbf{j} - \sin\phi\,\mathbf{k} \\ \mathbf{e}_\theta &= -\sin\theta\,\mathbf{i} + \cos\theta\,\mathbf{j} + 0\mathbf{k} \end{aligned}$$

轉化矩陣為正交矩陣（Orthogonal Matrix，逆矩陣即轉置矩陣）：

$$\begin{bmatrix} \mathbf{e}_\rho \\ \mathbf{e}_\phi \\ \mathbf{e}_\theta \end{bmatrix} = \begin{bmatrix} \sin\phi\cos\theta & \sin\phi\sin\theta & \cos\phi \\ \cos\phi\cos\theta & \cos\phi\sin\theta & -\sin\phi \\ -\sin\theta & \cos\theta & 0 \end{bmatrix} \begin{bmatrix} \mathbf{i} \\ \mathbf{j} \\ \mathbf{k} \end{bmatrix}$$
4微元（線元、面元、體積元）總結

位移向量微分：

$$d\mathbf{r} = d\rho\,\mathbf{e}_\rho + \rho\,d\phi\,\mathbf{e}_\phi + \rho\sin\phi\,d\theta\,\mathbf{e}_\theta$$

線元素平方度規：

$$ds^2 = d\rho^2 + \rho^2 d\phi^2 + \rho^2\sin^2\phi\,d\theta^2$$

面積微元：

$$dS_\rho = (h_\phi d\phi)(h_\theta d\theta) = \rho^2\sin\phi\,d\phi\,d\theta$$ $$dS_\phi = (h_\rho d\rho)(h_\theta d\theta) = \rho\sin\phi\,d\rho\,d\theta$$ $$dS_\theta = (h_\rho d\rho)(h_\phi d\phi) = \rho\,d\rho\,d\phi$$

體積微元（Griffiths 記為 $d\tau = r^2\sin\theta\,dr\,d\theta\,d\phi$）：

$$dV = h_\rho h_\phi h_\theta\,d\rho\,d\phi\,d\theta = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta$$

📐 完整嚴謹逐步推導詳解
1幾何關係分析與線性組合設定

令向量 $\mathbf{D} \equiv \mathbf{A} \times (\mathbf{B} \times \mathbf{C})$。

1. 根據外積定義，$\mathbf{D}$ 必垂直於向量 $(\mathbf{B} \times \mathbf{C})$。而 $(\mathbf{B} \times \mathbf{C})$ 垂直於 $\mathbf{B}$ 與 $\mathbf{C}$ 所在的平面。因此，$\mathbf{D}$ 必然平行（共面）於 $\mathbf{B}$ 與 $\mathbf{C}$ 所張成的平面！

故 $\mathbf{D}$ 必可表示為 $\mathbf{B}$ 與 $\mathbf{C}$ 的線性組合：

$$\mathbf{D} = \alpha \mathbf{B} + \beta \mathbf{C}$$
2垂直性條件求解係數比例

2. 同時，$\mathbf{D}$ 來自 $\mathbf{A} \times (\dots)$，故 $\mathbf{D}$ 必定與 $\mathbf{A}$ 正交垂直：

$$\mathbf{A} \cdot \mathbf{D} = 0$$

將 $\mathbf{D} = \alpha \mathbf{B} + \beta \mathbf{C}$ 代入點積式：

$$\mathbf{A} \cdot (\alpha \mathbf{B} + \beta \mathbf{C}) = \alpha (\mathbf{A} \cdot \mathbf{B}) + \beta (\mathbf{A} \cdot \mathbf{C}) = 0$$

移項得係數關係式：

$$\frac{\alpha}{\mathbf{A} \cdot \mathbf{C}} = \frac{-\beta}{\mathbf{A} \cdot \mathbf{B}} \equiv \gamma$$

其中 $\gamma$ 為某一純量待定常數。因此：

$$\alpha = \gamma (\mathbf{A} \cdot \mathbf{C}), \quad \beta = -\gamma (\mathbf{A} \cdot \mathbf{B})$$ $$\mathbf{D} = \gamma \left[ \mathbf{B}(\mathbf{A} \cdot \mathbf{C}) - \mathbf{C}(\mathbf{A} \cdot \mathbf{B}) \right]$$
3以 $x$ 分量決定常數 $\gamma = 1$

取 $\mathbf{e}_x \cdot \mathbf{D} = D_x$。右側展開：

$$D_x = \gamma \left[ B_x (\mathbf{A} \cdot \mathbf{C}) - C_x (\mathbf{A} \cdot \mathbf{B}) \right]$$

另一方面，直接計算三重積的 $x$ 分量：

$$D_x = \mathbf{e}_x \cdot [\mathbf{A} \times (\mathbf{B} \times \mathbf{C})] = (\mathbf{e}_x \times \mathbf{A}) \cdot (\mathbf{B} \times \mathbf{C})$$

利用純量三重積行列式計算：

$$\mathbf{e}_x \cdot [\mathbf{A} \times (\mathbf{B} \times \mathbf{C})] = \begin{vmatrix} 0 & -A_z & A_y \\ B_x & B_y & B_z \\ C_x & C_y & C_z \end{vmatrix} = A_z(B_x C_z - B_z C_x) + A_y(B_x C_y - B_y C_x)$$

重組項次：

$$= B_x(A_y C_y + A_z C_z) - C_x(A_y B_y + A_z B_z)$$

在兩括號內分別補上 $A_x C_x B_x$ 與相減項：

$$= B_x (A_x C_x + A_y C_y + A_z C_z) - C_x (A_x B_x + A_y B_y + A_z B_z) = B_x (\mathbf{A} \cdot \mathbf{C}) - C_x (\mathbf{A} \cdot \mathbf{B})$$

兩式對比，得證比例常數 $\gamma = 1$！

$$\mathbf{A} \times (\mathbf{B} \times \mathbf{C}) = \mathbf{B}(\mathbf{A} \cdot \mathbf{C}) - \mathbf{C}(\mathbf{A} \cdot \mathbf{B})$$

1計算體積分 $\int_V (\nabla \cdot \mathbf{v}) d\tau$

先求散度：

$$\nabla \cdot \mathbf{v} = \frac{\partial (xy)}{\partial x} + \frac{\partial (2yz)}{\partial y} + \frac{\partial (3zx)}{\partial z} = y + 2z + 3x$$

在單位立方體 $x, y, z \in [0, 1]$ 內進行三重體積分：

$$\int_V (\nabla \cdot \mathbf{v}) d\tau = \int_0^1 dx \int_0^1 dy \int_0^1 dz\,(3x + y + 2z)$$ $$= \int_0^1 3x\,dx \cdot (1)(1) + \int_0^1 y\,dy \cdot (1)(1) + \int_0^1 2z\,dz \cdot (1)(1)$$ $$= \frac{3}{2} + \frac{1}{2} + 1 = 3$$
2計算封閉表面六個面之通量和 $\oint_S \mathbf{v} \cdot d\mathbf{a}$
  • 面 1 ($x = 1$, $d\mathbf{a} = dy dz\,\hat{\mathbf{x}}$)：$\mathbf{v}\cdot d\mathbf{a} = (1\cdot y) dy dz \implies \int_0^1 \int_0^1 y\,dy dz = \frac{1}{2}$
  • 面 2 ($x = 0$, $d\mathbf{a} = -dy dz\,\hat{\mathbf{x}}$)：$\mathbf{v}\cdot d\mathbf{a} = -(0\cdot y) dy dz = 0$
  • 面 3 ($y = 1$, $d\mathbf{a} = dx dz\,\hat{\mathbf{y}}$)：$\mathbf{v}\cdot d\mathbf{a} = (2\cdot 1\cdot z) dx dz \implies \int_0^1 \int_0^1 2z\,dx dz = 1$
  • 面 4 ($y = 0$, $d\mathbf{a} = -dx dz\,\hat{\mathbf{y}}$)：$\mathbf{v}\cdot d\mathbf{a} = -(2\cdot 0\cdot z) dx dz = 0$
  • 面 5 ($z = 1$, $d\mathbf{a} = dx dy\,\hat{\mathbf{z}}$)：$\mathbf{v}\cdot d\mathbf{a} = (3\cdot 1\cdot x) dx dy \implies \int_0^1 \int_0^1 3x\,dx dy = \frac{3}{2}$
  • 面 6 ($z = 0$, $d\mathbf{a} = -dx dy\,\hat{\mathbf{z}}$)：$\mathbf{v}\cdot d\mathbf{a} = -(3\cdot 0\cdot x) dx dy = 0$

將六個面的表面通量相加：

$$\oint_S \mathbf{v} \cdot d\mathbf{a} = \frac{1}{2} + 0 + 1 + 0 + \frac{3}{2} + 0 = 3$$
$$\int_V (\nabla \cdot \mathbf{v}) d\tau = 3 = \oint_S \mathbf{v} \cdot d\mathbf{a}$$

2庫侖積分與奇偶性簡化

$$\mathbf{E} = \frac{1}{4\pi\epsilon_0} \int_{-L}^L \frac{\lambda dx}{r^2}\hat{\boldsymbol{r}} = \frac{1}{4\pi\epsilon_0} \int_{-L}^L \frac{\lambda(z\hat{\mathbf{z}} - x\hat{\mathbf{x}})}{(z^2 + x^2)^{3/2}} dx$$

拆解為 $x$ 與 $z$ 兩部分：

$$\mathbf{E} = \frac{\lambda}{4\pi\epsilon_0} \left[ z\hat{\mathbf{z}} \int_{-L}^L \frac{dx}{(z^2 + x^2)^{3/2}} - \hat{\mathbf{x}} \int_{-L}^L \frac{x dx}{(z^2 + x^2)^{3/2}} \right]$$

注意第二項被積函數 $\frac{x}{(z^2 + x^2)^{3/2}}$ 為關於 $x$ 的奇函數（Odd function），在對稱區間 $[-L, L]$ 上之定積分為零：

$$\int_{-L}^L \frac{x dx}{(z^2 + x^2)^{3/2}} = 0$$

故水平分量因對稱性完全抵消，僅存 $z$ 方向分量！

3計算定積分

利用標準積分公式 $\int \frac{dx}{(z^2 + x^2)^{3/2}} = \frac{x}{z^2 \sqrt{z^2 + x^2}}$：

$$\int_{-L}^L \frac{dx}{(z^2 + x^2)^{3/2}} = \left. \frac{x}{z^2 \sqrt{z^2 + x^2}} \right|_{-L}^L = \frac{L}{z^2 \sqrt{z^2 + L^2}} - \left( \frac{-L}{z^2 \sqrt{z^2 + L^2}} \right) = \frac{2L}{z^2 \sqrt{z^2 + L^2}}$$

代入電場表達式：

$$\mathbf{E} = \frac{1}{4\pi\epsilon_0} \frac{2\lambda L}{z\sqrt{z^2 + L^2}} \hat{\mathbf{z}}$$
4解答講義所提之兩大極限問題 (Limiting Cases)

問題 (1)：當 $z \to \infty$（場點遠離線段）？

當 $z \gg L$ 時，$\sqrt{z^2 + L^2} = z\sqrt{1 + (L/z)^2} \approx z$。代入得：

$$\mathbf{E} \approx \frac{1}{4\pi\epsilon_0} \frac{2\lambda L}{z(z)} \hat{\mathbf{z}} = \frac{1}{4\pi\epsilon_0} \frac{q_{\text{total}}}{z^2} \hat{\mathbf{z}}$$

其中 $q_{\text{total}} = 2\lambda L$ 為整個線段的總電荷。此結果表明：當觀察者距離極遠時，有限長度的線電荷縮為一個點，電場退化為標準點電荷平方反比場！

問題 (2)：當 $L \to \infty$（線段長度趨於無窮大，無限長直導線）？

當 $L \gg z$ 時，$\sqrt{z^2 + L^2} = L\sqrt{1 + (z/L)^2} \approx L$。代入得：

$$\mathbf{E} = \frac{1}{4\pi\epsilon_0} \frac{2\lambda L}{z(L)} \hat{\mathbf{z}} = \frac{1}{4\pi\epsilon_0} \frac{2\lambda}{z} \hat{\mathbf{z}} = \frac{\lambda}{2\pi\epsilon_0 z} \hat{\mathbf{z}}$$

此即無限長均勻帶電直線所產生的徑向電場公式（稍後將用高斯定律在數秒內再次導出），電場以 $1/z$ 衰減！

$$W_{\text{in}} = \frac{\epsilon_0}{2} \int_0^R \left( \frac{q r}{4\pi\epsilon_0 R^3} \right)^2 (4\pi r^2 dr) = \frac{q^2}{8\pi\epsilon_0 R^6} \int_0^R r^4 dr = \frac{q^2}{8\pi\epsilon_0 R^6} \frac{R^5}{5} = \frac{1}{40\pi\epsilon_0}\frac{q^2}{R}$$ $$W_{\text{out}} = \frac{\epsilon_0}{2} \int_R^\infty \left( \frac{q}{4\pi\epsilon_0 r^2} \right)^2 (4\pi r^2 dr) = \frac{q^2}{8\pi\epsilon_0} \int_R^\infty \frac{1}{r^2} dr = \frac{1}{8\pi\epsilon_0}\frac{q^2}{R}$$

總能量相加：

$$W_{\text{total}} = W_{\text{in}} + W_{\text{out}} = \left( \frac{1}{40} + \frac{1}{8} \right) \frac{q^2}{\pi\epsilon_0 R} = \frac{6}{40} \frac{q^2}{\pi\epsilon_0 R} = \frac{3}{5}\left( \frac{1}{4\pi\epsilon_0}\frac{q^2}{R} \right)$$

💡 核心物理觀念：第一唯一性定理與鏡像法原理
  • 邊界條件：在區域 $z > 0$ 內，拉普拉斯／帕松方程式為 $\nabla^2 V = -\frac{q}{\epsilon_0}\delta^3(\mathbf{r} - d\hat{\mathbf{z}})$。邊界條件為：(1) 在導電平面上 $V(x, y, 0) = 0$；(2) 在無窮遠處 $V \to 0$。

📐 完整嚴謹逐步推導詳解
1求電位分佈 $V(x, y, z)$

真電荷 $+q$ 位於 $(0, 0, d)$，鏡像電荷 $-q$ 位於 $(0, 0, -d)$。在 $z > 0$ 區域，任意點 $(x, y, z)$ 的電位由兩電荷疊加：

$$V(x, y, z) = \frac{1}{4\pi\epsilon_0} \left[ \frac{q}{\sqrt{x^2 + y^2 + (z - d)^2}} - \frac{q}{\sqrt{x^2 + y^2 + (z + d)^2}} \right]$$

驗證邊界條件：當 $z = 0$ 時，兩分母皆為 $\sqrt{x^2 + y^2 + d^2}$，兩項精確相消，得 $V = 0$；當 $r \to \infty$ 時，$V \to 0$。條件全數滿足！

2求感應面電荷密度 $\sigma$ 與總感應電荷 $Q$

由導體表面邊界條件，感應面電荷密度為：

$$\sigma = -\epsilon_0 \left. \frac{\partial V}{\partial z} \right|_{z=0}$$

對 $z$ 求偏微分：

$$\frac{\partial V}{\partial z} = \frac{q}{4\pi\epsilon_0} \left[ \frac{-(z - d)}{\left[ x^2 + y^2 + (z - d)^2 \right]^{3/2}} - \frac{-(z + d)}{\left[ x^2 + y^2 + (z + d)^2 \right]^{3/2}} \right]$$

代入 $z = 0$：

$$\left. \frac{\partial V}{\partial z} \right|_{z=0} = \frac{q}{4\pi\epsilon_0} \left[ \frac{d}{(x^2 + y^2 + d^2)^{3/2}} + \frac{d}{(x^2 + y^2 + d^2)^{3/2}} \right] = \frac{1}{4\pi\epsilon_0} \frac{2qd}{(x^2 + y^2 + d^2)^{3/2}}$$

因此感應面電荷密度為：

$$\sigma(x, y) = -\epsilon_0 \left. \frac{\partial V}{\partial z} \right|_{z=0} = \frac{-qd}{2\pi (x^2 + y^2 + d^2)^{3/2}}$$

在柱座標下積分全平面求總感應電荷 $Q$（令 $r^2 = x^2 + y^2$，$da = 2\pi r dr$）：

$$Q = \int \sigma da = \int_0^\infty \frac{-qd}{2\pi (r^2 + d^2)^{3/2}} (2\pi r dr) = -qd \int_0^\infty \frac{r dr}{(r^2 + d^2)^{3/2}}$$

令 $u = r^2 + d^2$，$du = 2r dr$：

$$Q = -qd \left[ -\frac{1}{\sqrt{r^2 + d^2}} \right]_0^\infty = -qd \left( 0 - \left( -\frac{1}{d} \right) \right) = -q$$

結論：平面上感應出的總電荷恰為 $-q$！所有由 $+q$ 出發的電力線全數終止於接地平面上！

3受力與系統靜電能量對比

電荷 $q$ 受到的吸引力即為它與感應電荷（等效於鏡像電荷 $-q$）的作用力。兩者相距 $2d$：

$$\mathbf{F} = -\frac{1}{4\pi\epsilon_0} \frac{q^2}{(2d)^2} \hat{\mathbf{z}} = -\frac{1}{4\pi\epsilon_0} \frac{q^2}{4d^2} \hat{\mathbf{z}}$$

計算將 $q$ 從 $\infty$ 移至 $d$ 所需作的功 $W$：

$$W = -\int_\infty^d \mathbf{F} \cdot d\mathbf{l} = -\int_\infty^d \left( -\frac{1}{4\pi\epsilon_0} \frac{q^2}{4z^2} \right) dz = \frac{q^2}{16\pi\epsilon_0} \left[ -\frac{1}{z} \right]_\infty^d = -\frac{1}{4\pi\epsilon_0} \frac{q^2}{4d}$$

  • 由 (ii) $Y(a) = 0 \implies \sin(ka) = 0 \implies k a = n\pi \implies k = \frac{n\pi}{a} \quad (n = 1, 2, 3, \dots)$。

$$V(x, y) = \sum_{n=1}^\infty C_n e^{-n\pi x/a} \sin\left(\frac{n\pi y}{a}\right)$$

$$V(x, y) = \frac{4V_0}{\pi} \sum_{n=1,3,5,\dots}^\infty \frac{1}{n} e^{-n\pi x/a} \sin\left(\frac{n\pi y}{a}\right)$$

$$V(r, \theta) = \sum_{l=0}^\infty \left( A_l r^l + \frac{B_l}{r^{l+1}} \right) P_l(\cos\theta)$$

$$\int_0^\pi P_l(\cos\theta) P_{l'}(\cos\theta) \sin\theta\,d\theta = \frac{2}{2l + 1} \delta_{l l'}$$
2例題 3.6：球內部解 ($r \le R$)

在球心 $r = 0$ 處，電位必須為有限值，不能發散。因此所有 $B_l$ 必須全為零（$B_l = 0$）：

$$V(r, \theta) = \sum_{l=0}^\infty A_l r^l P_l(\cos\theta)$$

在球表面 $r = R$ 處匹配邊界條件 $V(R, \theta) = V_0(\theta)$：

$$\sum_{l=0}^\infty A_l R^l P_l(\cos\theta) = V_0(\theta)$$

3例題 3.7：球外部解 ($r \ge R$)

$$V(r, \theta) = \sum_{l=0}^\infty \frac{B_l}{r^{l+1}} P_l(\cos\theta)$$

同理在表面匹配正交性，解得：

$$B_l = \frac{2l + 1}{2} R^{l+1} \int_0^\pi V_0(\theta) P_l(\cos\theta) \sin\theta\,d\theta$$
4例題 3.8：均勻外加電場中之導電球求解

邊界條件：

  1. (i) 金屬球表面等電位，取其電位為零：$V(R, \theta) = 0$；
  2. (ii) 當 $r \gg R$ 時，恢復均勻電場 $\mathbf{E}_0 = E_0\hat{\mathbf{z}} \implies V \to -E_0 z = -E_0 r\cos\theta$。

$$\sum_{l=0}^\infty A_l r^l P_l(\cos\theta) \to -E_0 r P_1(\cos\theta) \quad (\text{因 } P_1(\cos\theta) = \cos\theta)$$

直接比對各階係數：只有 $l = 1$ 的項存在，且：

$$A_1 = -E_0, \quad A_l = 0 \; (\forall l \ne 1)$$

$$\left( A_l R^l + \frac{B_l}{R^{l+1}} \right) = 0 \implies B_l = -A_l R^{2l+1}$$

當 $l \ne 1$ 時，$A_l = 0 \implies B_l = 0$；當 $l = 1$ 時：

$$B_1 = -(-E_0) R^{2(1)+1} = E_0 R^3$$

$$V(r, \theta) = -E_0\left( r - \frac{R^3}{r^2} \right) \cos\theta$$

計算感應面電荷密度 $\sigma(\theta)$：

$$\sigma(\theta) = -\epsilon_0 \left. \frac{\partial V}{\partial r} \right|_{r=R} = -\epsilon_0 \left. \left[ -E_0 \left( 1 + \frac{2R^3}{r^3} \right) \cos\theta \right] \right|_{r=R} = \epsilon_0 E_0 (1 + 2)\cos\theta$$
$$\sigma(\theta) = 3\epsilon_0 E_0 \cos\theta$$

$$\mathbf{F} = q\mathbf{E} \implies \mathbf{E} \text{ 必須從各方向皆指向 } P$$

以 $P$ 為中心取一任意小的球面高斯面 $S$。由於電場 $\mathbf{E}$ 在整個球面上處處指向球心 $P$，電場的向外總通量必為負值：

$$\oint_S \mathbf{E} \cdot d\mathbf{a} < 0$$

$$\oint_S \mathbf{E} \cdot d\mathbf{a} = 0$$

$$\left. \frac{\partial V_{\text{out}}}{\partial r} \right|_{r=R} - \left. \frac{\partial V_{\text{in}}}{\partial r} \right|_{r=R} = -\frac{\sigma}{\epsilon_0} = -\frac{k}{\epsilon_0}\cos\theta = -\frac{k}{\epsilon_0} P_1(\cos\theta)$$

代入微商項：

$$\sum_{l=0}^\infty \left[ -(l+1)\frac{B_l}{R^{l+2}} - l A_l R^{l-1} \right] P_l(\cos\theta) = -\sum_{l=0}^\infty (2l + 1) A_l R^{l-1} P_l(\cos\theta)$$

比對 $l=1$ 項：$-(2(1) + 1) A_1 R^0 = -\frac{k}{\epsilon_0} \implies A_1 = \frac{k}{3\epsilon_0}$（其餘階數全為 0）。$B_1 = A_1 R^3 = \frac{k R^3}{3\epsilon_0}$。

$$V_{\text{in}}(r, \theta) = \frac{k}{3\epsilon_0} r\cos\theta = \frac{k}{3\epsilon_0} z, \quad V_{\text{out}}(r, \theta) = \frac{k R^3}{3\epsilon_0 r^2} \cos\theta$$

物理亮點：球殼內部為均勻電場 $\mathbf{E}_{\text{in}} = -\frac{k}{3\epsilon_0}\hat{\mathbf{z}}$！球外則為純電偶極場！

題目文字辨識 (Problem Statement)
Problem 3.30: Four particles (one of charge $+q$, two of charge $-q$, and one of charge $+q$) are placed on the $z$-axis at $z = d, 0, -d$ (linear quadrupole with $-2q$ at origin). Find the leading term in the multipole expansion of the potential.
題目中文精準翻譯
習題 3.30：四個帶電粒子置於 $z$ 軸上：$+q$ 在 $z = +d$、$-2q$ 在原點 $z = 0$、$+q$ 在 $z = -d$（構成典型線性電四極子）。求其遠距電位多極展開之主導項（Leading Term）。
📐 完整嚴謹逐步推導詳解
1多極展開階數檢驗

1. 單極項（Monopole Term）：

$$Q_{\text{mono}} = \sum q_i = (+q) + (-2q) + (+q) = 0 \implies V_{\text{mono}} = 0$$

2. 偶極矩（Dipole Moment）：

$$\mathbf{p} = \sum q_i \mathbf{r}_i' = q(d\hat{\mathbf{z}}) + (-2q)(0) + q(-d\hat{\mathbf{z}}) = \mathbf{0} \implies V_{\text{dip}} = 0$$

單極矩與偶極矩均為零！故最低非零項必為四極項（Quadrupole Term, $n = 2$）！

2四極項計算與勒壤得多項式

多極展開公式通式：

$$V(\mathbf{r}) = \frac{1}{4\pi\epsilon_0} \sum_{n=0}^\infty \frac{1}{r^{n+1}} \sum_{i} q_i (r_i')^n P_n(\cos\alpha_i)$$

對於 $n = 2$：

$$\sum_i q_i (r_i')^2 P_2(\cos\theta_i) = q(d)^2 P_2(\cos 0) + (-2q)(0) + q(d)^2 P_2(\cos\pi)$$

由於 $\cos 0 = 1, \cos\pi = -1$，且 $P_2(1) = P_2(-1) = 1$：

$$\sum = q d^2 (1) + 0 + q d^2 (1) = 2 q d^2$$

因此在場點 $(r, \theta)$ 處，由勒壤得多項式 $P_2(\cos\theta) = \frac{1}{2}(3\cos^2\theta - 1)$：

$$V(\mathbf{r}) \approx \frac{1}{4\pi\epsilon_0} \frac{2qd^2 P_2(\cos\theta)}{r^3} = \frac{1}{4\pi\epsilon_0} \frac{qd^2 (3\cos^2\theta - 1)}{r^3}$$

電四極子電位以 $1/r^3$ 速率衰減，角分佈具有 $(3\cos^2\theta - 1)$ 的四極特徵！
